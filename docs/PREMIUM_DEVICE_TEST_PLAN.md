# PREMIUM 演出 実機テスト計画

CI の widget test で overflow・構造は確認済み。本計画は**GPU描画負荷・フレーム安定性・音/ハプティクスの段階演出**を対象とする。

## 検証デバイス

| デバイス | 画面サイズ | 用途 | 優先度 |
|----------|-----------|------|--------|
| 低-end Android（Snapdragon 6系以下） | 720×1280 | パフォーマンス境界線 | ★★★ |
| 中端 Android（Snapdragon 7系） | 1080×2400 | 主力テスト | ★★★ |
| 小型 Android（5.0インチ以下） | 360×640 | overflow確認 | ★★★ |
| 高端 Android（Snapdragon 8系） | 1440×3200 | 基準値 | ★★ |

## フレーム時間目標

| 指標 | 目標 | 許容 | ブロッカー |
|------|------|------|-----------|
| 平均フレーム時間 | ≤11.1ms (90fps) | ≤16.6ms (60fps) | ＞22ms |
| 1%ile フレーム時間 | ≤16.6ms | ≤22ms | ＞33ms |
| ジャンクフレーム率 | ＜1% | ＜3% | ＞5% |
| メモリ使用量増分 | ≤30MB | ≤50MB | ＞80MB |

## テスト項目

| # | テスト項目 | 合格条件 |
|---|-----------|---------|
| T-01 | `7×1111` でPREMIUM発動 | NORMAL→CHANCE→激熱→暗転→復活→PREMIUMの6ビートと結果解放が全て表示される |
| T-02 | ランダムPREMIUM（100回試行） | 1回以上発動する |
| T-03 | SKIPボタン | 通常ビート・暗転・結果解放の各フェーズから結果画面に即遷移する |
| T-04 | フレームレート（中端） | DevTools平均≤16.6ms |
| T-05 | フレームレート（低-end） | DevTools平均≤22ms、ジャンク＜5% |
| T-06 | メモリリーク（10回連続発動→SKIP） | メモリ収束（50MB以内） |
| T-07 | Reduce Motion ON | 常時アニメーション・揺れ・フラッシュ停止、テキスト・静的装飾は表示 |
| T-08 | 音・ハプティクス段階 | 表示ランクに応じたSEになり、暗転ビートは完全無音・無振動、復活/PREMIUMで強くなる |
| T-09 | 結果クライマックス | 長い指数表記でも画面内に収まり、1.5秒表示またはSKIPで終了する |
| T-10 | 高強度描画 | 盤面ランプ・流星・PREMIUM稲妻追加後もフレーム時間目標を満たす |

## 測定方法

```bash
flutter run --profile -d <device_id>
# DevTools → Performance → 録画開始 → 7×1111= → 演出完了まで待機 → 停止
```
