# ドパ電卓 MVP仕様

## 1. Goal

日常の四則演算を正確に行える普通の電卓に、計算結果確定時だけ過剰なパチンコ風演出を加え、短時間で笑える体験を作る。

## 2. 完了条件

1. 四則演算・小数・負数が正しく計算できる。
2. 0除算や未完成式でクラッシュしない。
3. `=` 押下後、計算結果は変更せず演出だけ抽選される。
4. 演出はSKIPできる。
5. 7系結果はプレミア演出になる。
6. UIは1画面で完結する。

## 3. UX

### 通常操作

数字・演算子入力 → `=` → 複数段階の煽り演出 → 結果表示

### 演出抽選

- NORMAL: 70%
- CHANCE: 20%
- 激熱: 9%
- PREMIUM: 1%

特殊結果は確率を上書きする。

### 特殊結果

- `7`, `77`, `777`, `7777`, `8192`: PREMIUM
- `0`: 激熱「全消灯」

## 4. 非機能

- オフライン動作
- 計算内容を外部送信しない
- ネットワーク権限不要
- 結果確定ロジックと演出抽選を分離
- 演出中もSKIP可能

## 5. 著作権・表現

実在する遊技機のロゴ、機種名、キャラクター、固有SE、固有役物デザインをコピーしない。演出は「パチンコ的な文法」に留め、素材・文言・音源はオリジナルとする。
